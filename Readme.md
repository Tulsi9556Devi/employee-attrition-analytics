# 📊 Employee Attrition Analytics & Prediction

An interactive machine learning dashboard that analyzes employee
attrition patterns and estimates employee attrition risk based on
historical HR data.

## 🚀 Features

- Interactive employee attrition analytics
- Workforce data visualization
- Attrition analysis by overtime and job satisfaction
- Department-level analysis
- Income distribution analysis
- Logistic Regression classification model
- Model accuracy and ROC-AUC evaluation
- Interactive employee attrition risk prediction
- Streamlit-based dashboard

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Plotly
- Streamlit
